# Signa Progress

## Signing assurance correction — 2026-10-06

See [signing-assurance.md](signing-assurance.md) for the pinned DocuSeal comparison, implemented CMS/TSA/DSS corrections, named/active signing identities, encrypted-key upgrade and production prerequisites. Earlier entries below describing PAdES/LTV or an embedded document timestamp are historical implementation notes, not certification. The new flow embeds a validated CMS signature timestamp. Public trust requires approved provider credentials; the HSM adapter boundary exists but no remote provider is connected.

Revocation validation was extracted from the existing collector. The settings container was reduced and timestamp verification extracted. AccountsService remains an existing oversized file with a small net increase for transactional certificate operations; broader service decomposition is deferred to avoid unrelated changes. The collector remains a split candidate over the 500-line guardrail; ASN.1 parsing/validation routines and cryptographic fixture tests intentionally retain contiguous longer functions for reviewability.
